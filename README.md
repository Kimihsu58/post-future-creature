# 深海圖靈利維坦 • 3D 游動模擬

Blender 5.2 Model & Topology × p5.js WEBGL

一隻程序化建模的深海蝠翼利維坦，在瀏覽器裡即時做頂點波浪游動、
Voronoi 腹膜蠕動、生物螢光發光，並**自主漫遊一整片環境**。
環境有兩種可即時切換：**深海**（海床沙丘、礁岩、海洋雪）與
**逆世界（怪奇物語風）**（枯樹、地面藤蔓、碎石、獵物骨骸堆、灰燼、
每 5~13 秒的紅色雙閃閃電、背後襯著紅色風暴光暈的遠處巨影）。另有**抽象形變**參數，把角色從可辨認的
蝠翼造型扭成不定形的東西（流場位移、軸向扭轉、漂浮碎片、脫離頭部的複眼）。
逆世界裡有 **3 隻六腳地行獸**在紅土上游蕩；按 F 可捕食 —— 整隻拖進嘴裡吞下，
**每吞一隻就更像「威可那」式的人形異形**（蒼白屍皮浮現黑紅血管皺褶、
吻端長出眉脊/鼻梁/黑眼窩/嘴縫的人臉、身體兩側長出**張開的五指人手**、
背棘變粗成脊椎骨節、複眼轉成蒼白死眼、觸手收短；
HUD 即時顯示「進食 / 目前演化階段」）。
模型資料由 Blender 5.2 腳本產生，p5.js 直接讀取後在 WEBGL 即時渲染與動畫。

## 音效（Web Audio 程序合成 · 零音檔）

全部即時合成、不載任何音檔（離線可用），`audio.js` 一個檔案搞定：

| 聲音 | 觸發時機 | 合成方式 |
| --- | --- | --- |
| 生物嘶吼 | 按 F 發動捕食 | 鋸齒波下滑 + 氣聲帶通 + 次低音 + 13~21Hz 振幅抖動 + tanh 削波 |
| 咬擊 | 地行獸被咬住/觸手纏住 | 短促高音嘶吼（0.5s） |
| **扭塑膠聲** | 整段吞食過程（0.85s / 觸手 2.4s） | 密集隨機噼啪爆裂（帶通白噪）+ 高 Q 啾鳴頻率階梯（stick-slip 扭擠）+ 低鳴底層 |
| 吞食爆響 | 整隻吞下瞬間 | 18 連爆裂 + 120→38Hz 低鳴「咕」 |
| 進化嘶吼+扭擠 | 每次人形化 +1 | 1.7 秒身體重組扭聲 + 1 秒後接一聲嘶吼 |

- 瀏覽器自動播放政策：**第一次點擊/按鍵**才會解鎖 AudioContext（之後才有聲音）
- master 後面接壓限器，多層疊加不破音；靜音狀態持久化（`localStorage.sfxMuted`）

### 網址參數（方便分享 / 除錯）

```
index.html?shade=glow&cam=head&env=up&abs=75&speed=2.5&yaw=1.5&pitch=0.3&dist=8
```

- `shade` = skin / wire / glow　`cam` = orbit / follow / head　`env` = up / sea
- `speed,spine,wing,belly,tent,bio,abs` = 七組參數數值（原右側滑桿；`tent` = 觸手擺動、`abs` = 抽象形變 0~100）
- `yaw,pitch,dist` = 初始相機
- `roamsec=N` = 開場前先同步跑 N 秒漫遊（固定步長，除錯/重現路徑用；地行獸會一起預跑）
- `hunt=1` = 開場立即發動捕食（配合 `roamsec` 可重現追擊/捕食過程）
- `walkers=N` = 地行獸數量（1~5，預設 3）
- `meals=N` = 預設進食次數（人形化 0~6，除錯/截圖用）
- `swallow=1` = 開場就讓最近的一隻地行獸開始被吞
  （`swallow=hold` = 凍結在吞到一半，截圖用）
- `burst=1` = 原地放一團捕食爆點（爆點視覺除錯用）
- `flash=N` = 強制固定紅色閃電亮度 0~1（除錯/截圖用）
- `bolt=x,y` = 強制閃電劈在指定世界座標（配合 `flash=1` 截圖電光用；不設為隨機）
- `post=0` = 關閉後製管線（直接渲染，A/B 比較畫質用）
- `fx=0` = 後製效果全關（只留 framebuffer 純取樣，除錯用）
- `ss=1` = 關閉 2× 超取樣（省效能；預設開）

## 兩種環境與自主漫遊

- **利維坦自主巡游**：正弦合成的游走方向、限制轉速的轉向、入彎自動側傾、
  上浮抬頭 / 下潛低頭的俯仰；深度在 −9.2 ~ −1.6 之間起伏，水平半徑
  20 起被柔性拉回中心（硬邊界 34）。**障礙迴避**：太靠近礁岩 / 枯樹 /
  巨影腿腳就朝外側繞開，不會穿模。「游動波速」參數（`?speed=`）同時控制波浪頻率與前進速度。
- **三種相機都追著生物**：
  - 自由環視 — 目標點軟跟生物（右鍵平移後 6 秒內不干擾），旋轉縮放完全自由
  - 跟隨追蹤 — 鏡頭追在正後方的追蹤視角（左鍵拖曳可加視角偏移）
  - 頭部特寫 — 鏡頭鎖定頭部、在正前方回望臉
- **深海（sea）**：110×110 海床沙丘（著色/線框吃同一份網格）、8 顆半埋礁岩、
  300 顆圍著生物飄落的海洋雪（螢幕定大小、依霧化分層）、藍灰水色霧。
- **逆世界（up，怪奇物語風）**：同片海床換成乾裂暗紅土；9 棵程序化枯樹
  ＋14 棵遠景近黑剪影（圍在活動範圍外，霧吃成剪影）、5 條沿海床蜿蜒的疙瘩藤蔓、
  40 片地面深色碎屑斑塊；灰燼取代海洋雪；
  每 5~13 秒一次**雙閃紅色閃電**（紅光掃過所有表面，背景與霧同步紅移）；
  遠處一尊緩慢擺動的**巨大黑影**（高塔 + 撐地粗腳 + 垂落觸鬚），背後襯著
  8 層疊出的**紅色風暴光暈**→ 黑塔永遠是剪影。切換方式：`?env=up` / `?env=sea`。
- **距離霧**：GLSL 指數霧把遠處景物融進該環境的底色（`background()` 用同一份
  色表 → 背景 = 霧色，閃電瞬間一起紅移、地平線無色縫；頂點做世界座標化，
  生物無論游到哪裡、光照與霧都正確）。
- **擬真天空與大氣（兩種環境共用）**：r=150 天空穹頂做垂直漸層
  （天頂 → 地平線 → 地平線下融進霧色、無色縫；閃電整片紅移）；
  逆世界另有 9 朵公告牌**暗紅雲團**（緩慢環繞漂移、閃電瞬間被照亮、
  用 depthMask 關深度 → 實體能正確遮擋）；7 团**貼地霧團**沿地面緩飄
  （比霧色稍亮的不規則軟圓盤）。純發光模式天空/雲/霧自動壓暗；線框模式只留天空。
- **畫質升級：2× 超取樣 + 後製管線**（新檔 `post.js`）：
  - **整個 3D 場景先畫進 framebuffer**（離屏畫布，2 倍解析度渲染再縮小
    → 邊緣變平滑，等效反鋸齒；`?ss=1` 可關閉省效能）。
  - **後製 shader 對整張畫面統一上質感**：
    1. **泛光 Bloom** — 亮部（複眼/閃電/螢光邊）往外暈開，電影感的關鍵
    2. **色散 CA** — 畫面邊緣 R/B 輕微分離，模擬真實鏡頭色差
    3. **銳化** — unsharp mask 補償縮放柔化，細節更利
    4. **Filmic 調色** — 輕 S 曲線壓高光＋飽和微增，告別灰扁
    5. **暗角 Vignette** — 四角壓暗，目光集中到中央生物
    6. **膠片顆粒** — 極輕微動態雜訊，消除數位乾淨感
  - 各效果強度集中在 `sketch.js` 的 `draw()` 裡（想找不同氣氛直接改數值）。
  - 除錯：`?post=0` 完全跳過後製（A/B 比較）、`?fx=0` 只留純取樣、
    `?ss=1` 關超取樣、`?flipy=0/1` 校正 framebuffer 上下方向。
- **材質寫實化（GLSL 升級）**：
  - **程序化微觀凹凸** — 3D 值噪聲梯度擾動法線 → 岩石/沙地/皮層有顆粒
    皺褶，不再像光滑塑膠（依距離淡出防遠景閃爍）。
  - **Blinn-Phong 高光** — 頂光＋補光各一盞；生物濕潤表皮又小又亮的
    反光斑、甲殼稍澀、岩石幾乎無高光（每組材質各給一組參數）。
  - **假環境光遮蔽** — 朝下的面偏暗 → 貼地感（低伏的地行獸遮蔽最重）。
  - **半球環境光** — 上下面吃不同環境色（天光/地面反照）。
- **動態氛圍（讓場景更生動）**：**森林風擺** —— 樹離地越高擺得越大、
  藤蔓整條微微蠕動，閃電瞬間陣風加劇（樹梢狂掃）；**上升微粒 ×80** ——
  逆世界是忽明忽暗的紅熱餘燼、深海是青白氣泡，到頂重生、圍著生物捲動；
  **雲隙微閃** —— 兩道閃電之間天空偶爾微微亮一下（雲後遠雷的感覺）；
  **深海光柱 ×6** —— 高處透下的柔和光帶（直立公告牌、頂端緩擺、上亮下淡、
  遠的沉進霧色；純發光模式自動壓暗）。
- **寫實環境強化**：
  - **碎石與貝殼殘骸 ×36** —— 變形小球貼著起伏地面散布（兩種環境共用），
    底色吃環境色、頂面偏亮，大的會投接地陰影 → 地面不再空蕩。
  - **獵物骨骸堆 ×3** —— 一段脊椎管 + 5 條肋骨弧的白化骨堆（吃剩的殘渣），
    為生存痕跡鋪出「這裡有掠食者」的氛圍（深海 = 鯨落）。
  - **地表大尺度色斑（uMottle）** —— 只給海床/紅土開的大尺度噪聲斑駁，
    底色明暗 + 暖色漂移 → 沙丘/紅土有大片色塊變化，不再一整片均勻。
  - **遠景山脊** —— 半徑 95~125 一圈高低起伏的黑色丘陵剪影
    （深海=海底山脊、逆世界=焦黑山群），地平線從此有遠近層次。
  - **閃電實體** —— 打閃瞬間一道隨機折線電光從雲底劈到地面
    （白熱核心＋紅暈外層、1~2 條分叉、約 0.5 秒殘影消散；
    每次「亮起瞬間」重建一條新折線；`?bolt=x,y` 可指定劈落位置）。
  - **接地陰影** —— 樹/礁岩/巨影腳下與兩隻生物下方的柔軟暗斑
    （貼地多圈羽化圓盤；生物離地越高 → 陰影越大越淡）。
  - **深海底光** —— 海床上 10 团緩移的柔亮光斑（模擬上方散射光在沙丘上
    游走，明暗呼吸）；純發光模式陰影/底光自動壓暗。
- **地行獸 ×3（第二種生物，逆世界專屬）**：六腳甲獸（新檔 `walker.js`，`?walkers=N` 可改 1~5）
  —— 甲殼/頭/尾刺是旋轉體、六條腿與雙觸鬚每幀重算管子路徑；**交替三角步態**
  （三隻跨步起弧、三隻踩地支撐）貼著起伏紅土行走，走走停停「聞一聞」，
  自動避開枯樹與礁岩，**同伴之間保持 ~2.2 距離**（不會疊在一起、出生點也分散 ≥5）；
  琥珀色雙眼脈動微光。深海不出現（切環境時不更新不繪製）。
- **捕食鍵（F）**：利維坦自動鎖定「最近的活地行獸」俯衝追擊（速度 ×2.6、轉速加快、
  壓低到地面高度、無視邊界拉回），12 秒追不到就放棄；被追的那隻**轉頭狂奔**
  （速度 2.15、急轉彎、跨大步、暫停行為取消），離掠食者 ~10 內的**同伴跟著散開**
  （速度 1.7）。抓到判定 = 水平 4.5 內＋俯衝到位（嘴巴在身體前方 ~2 單位；
  近距離自動收斂轉向、減速配速 → 不會被急轉獵物甩開掃圈）。
  抓到 → **整隻吞下去**：0.85 秒動畫（身體往嘴裡加速插值 + 全身等比縮到 5% +
  吸入翻滾，頂點每幀實算旋轉/縮放/平移）→ 嘴邊爆一團拋物線餘燼 →
  **進食數 +1、演化跳到下一段**（橫幅公告新階段名稱）→
  7 秒後在遠處重生（避開掠食者、障礙與同伴）；
  捕食後 10 秒冷卻。
  HUD 顯示「咬住了 / 整隻吞下（第 N 隻）→ 進化：○○ / 逃走了」提示橫幅與
  「🍖 進食 / 🧬 目前演化階段」即時統計；主控台每秒記錄
  `[hunt] t/d/z` 追擊狀態與事件（除錯用）。
- **階段式演化（身體改造：每吞一隻長出一個新人體部位，6 隻長成完整人形）** ——
  `levi.meals` 計數持久累積；HUD「🧬 人形化」顯示目前階段名稱 + 完成度%：

  | 進食 | 階段 | 解鎖的形態變化 |
  |---|---|---|
  | 0 | 原始 | ——（藍色蝠形原生體，在空中游動） |
  | 1 | Ⅰ 軀幹直立 | 蝠翼身**站起來**收窄成直立人形軀幹（臀寬→腰細→胸寬→頸細的輪廓）；皮膚轉蒼白屍皮（`uAlien` 30% 起步）；腹膜/觸手開始收進身體 |
  | 2 | Ⅱ 頭部成形 | **頸 + 蛋形頭**從頸根長出來；眉脊 + 深色眼窩×2 + 蒼白眼球**搬到頭上**（臉一出生就在人頭正面）；複眼定型蒼白死眼 |
  | 3 | Ⅲ 雙臂成形 | 肩→肘→腕**人形手臂**從上胸兩側伸出、自然下垂；**鼻梁 + 嘴縫**補完人臉；背棘退化成小骨節凸點 |
  | 4 | Ⅳ 雙腿萌生 | **短腿**（大腿+小腿+腳掌）從髖部长出；身體同步**降到地面**準備站立 |
  | 5 | Ⅴ 雙腿成形 | 腿長滿、**站在海床上**（腳掌貼地 IK）；五指人手完全張開 |
  | 6 | Ⅵ 人形步態 | **開始用腳走路**：步行週期（兩腳交替跨步、抬腳弧線）+ 擺臂（與腳相反）+ 膝蓋朝前彎的兩段 IK；步頻跟地面速度連動 → 腳掌不打滑 |

  各部件的生長量都用「解鎖階段 → 漸進長滿到第 6 隻」的比例餵公式，
  所以**每一階都有新的可見變化**，之前已有的特徵會繼續長完整。
  程序細節：軀幹用「逐頂點形變目標」（蝠翼座標 → 人形座標插值）；頭/腿/手臂
  是程序化管件（拓撲建一次、每幀重寫頂點）；腿的落腳點先算「世界座標」再用
  旋轉轉置反算回局部 → 經姿態矩陣後正好踩在起伏的海床上。
- **姿態矩陣在 JS 端算**（Rz·Ry·Rx 旋轉 + 平移）→ 頂點/法線轉成世界座標
  再丟給 GPU，不用 GL push/pop，也讓着色器拿到真正的世界位置。

## 部件（Blender 拓撲 + 程序化觸手）

1. **主軀幹** — 變形 UV 球 → 蝠翼流線體，Y 軸向後流體波動傳遞
2. **腹膜** — 網格膜，p5 端用 Voronoi 細胞做呼吸蠕動
3. **複眼** — 貼著頭部表面的電光青小球群（呼吸脈動發光）
4. **觸手 ×16** — 程序化管狀 tube（頭頂環 6 ＋ 面下腕足 6 ＋ 腹部垂鬚 4）：
   每幀重算路徑（行進波甩動 + 重力下垂 + 海床夾制不穿地），
   由 `?tent=` 參數控制晃幅

> 原角冠（3D DLA 珊瑚）與羽鬚（L-System 蕨狀感應鬚）已依需求**刪除**
> —— 載入 data 時直接丟棄這四個部件，不再渲染。

## 着色模式

- **有機深海皮層** — 環境光 + 頂光（深海=白、逆世界=風暴暗紅）+ 攝影機探照燈補光
  + 菲涅爾螢光邊 + 次表面暖光；閃電瞬間所有表面疊一層紅色片光
- **線框骨骼 (Wire)** — 全模型唯一邊線框（線寬依相機距離換算成穩定像素）；
  世界線框依環境過濾（枯樹/藤蔓/巨影只在逆世界出現）
- **純生物發光** — 身體壓暗、只留電光青螢光輪廓與脈動複眼

## 抽象形變（`?abs=` 參數，0~100，預設 75）

把「可辨認的蝠翼動物」扭成不確定是什麼的東西；0 = 原始造型，越高越抽象：

1. **軸向扭轉** — 繞 Y 軸隨時間扭轉，蝠翼被扭成抽象帶狀
2. **非均勻比例呼吸** — 三軸比例各自縮放，身體一直在「不像動物」的比例間變形
3. **徑向流場位移** — 繞身體軸的「低頻平滑」大瓣起伏（沿身 1.1、角向 2 瓣；
   高頻皺褶已移除 → 軀幹平整整齊），每幀重算法線，光照貼著新表面
4. **複眼脫離** — 複眼按相連性自動分組，抽象 > 0 時各自脫離頭部鬆散漂浮
5. **抽象碎片** — 7 顆八面體繞身體軌道漂移自轉（抽象 < 5% 自動收起）
6. **氣息微動** — 附加在姿態上的呼吸位移（原本就有，抽象模式下更明顯）
